# Test Scenario: Codsblu v1.1.0 Intelligence & Validation

This scenario outlines how to test and verify the new capabilities introduced in **Codsblu (blublu) v1.1.0**:
1. Filesystem Fallback Scanner (`scripts/scanner.py`) in non-git directories.
2. Automated Mermaid syntax validation and graceful Markdown table fallback.
3. Staleness & Architecture Drift Detection (`--check-staleness`).

---

## Test Part A: Advanced Filesystem Scanner on Non-Git Directory

### Objective
Verify that `scripts/scanner.py` seamlessly detects changes on non-git directories without failing or throwing git errors.

### Execution
1. Navigate or point scanner to `tests/fixtures/non-git-app`:
   ```bash
   python scripts/scanner.py --path tests/fixtures/non-git-app --format json
   ```
2. **Expected Assertions**:
   - `mode` must be `"filesystem_fallback"`.
   - Initial scan generates `tests/fixtures/non-git-app/.agents/.cache_scan.json`.
3. Add a new file `tests/fixtures/non-git-app/src/helper.py`:
   ```python
   def format_output(val): return str(val).upper()
   ```
4. Re-run scanner:
   ```bash
   python scripts/scanner.py --path tests/fixtures/non-git-app --format json
   ```
5. **Expected Assertions**:
   - `added` contains `"src/helper.py"`.
   - `mode` remains `"filesystem_fallback"`.

---

## Test Part B: Automated Mermaid Validator & Graceful Fallback

### Objective
Verify that `scripts/validate-blueprint.py` catches syntax errors in Mermaid diagrams and outputs a structured Markdown relationship table fallback.

### Execution
Run the validator on `tests/fixtures/malformed-mermaid/.agents/codebase-map.md`:
```bash
python scripts/validate-blueprint.py --path tests/fixtures/malformed-mermaid/.agents/codebase-map.md
```

### Expected Assertions
1. **Exit Code**: Non-zero (`1`).
2. **Error Output**:
   - Catches unbalanced brackets `[` or unquoted label.
   - Catches malformed arrow `->`.
3. **Fallback Output**:
   The output contains a recommended replacement table:
   ```markdown
   | Source Module | Target Module | Relationship |
   | :--- | :--- | :--- |
   | App | AuthService | Dependency |
   | AuthService | UserDb | Dependency |
   ```

## Test Part C: Staleness & Architecture Drift Detection

### Objective
Verify that `--check-staleness` detects when source code files have been modified without corresponding blueprint updates.

### Execution
1. In `tests/fixtures/simple-node-app`, modify `src/services/userService.js` (e.g. add a comment or function).
2. Run validator with `--check-staleness`:
   ```bash
   python scripts/validate-blueprint.py --path tests/fixtures/simple-node-app/.agents/codebase-map.md --check-staleness
   ```
3. **Expected Assertions**:
   - Warning or error indicates `UserService` has modified files not synchronized in `.agents/codebase-map.md`.
